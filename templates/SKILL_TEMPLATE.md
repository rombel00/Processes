**Пиши черновик на диск после каждой фазы**, а не только в конце:

что артефакта ещё нет. Это прямо ломает главное свойство системы — работа
восстановима из файлов, а не из разговора.

## Результат

**Этот раздел общий для интерактивного и автономного режима, если они у
скилла оба есть.** Не переноси инструкцию «запиши на диск» внутрь описания
только одного из режимов — шесть скиллов волн 1–2 уже наступили на эту
грабли: интервью заканчивалось словами «выдай чистовую версию» без записи
файла, и работа целого диалога оставалась только в истории чата.

Запиши артефакт в `<путь>` и верни:

```json
{
  "status": "done",
  "artifacts": ["<путь>"],
  "assumptions": [],
  "blocking_questions": []
}
```

Если завис вопрос класса Б (`PROCESS.md`, «Блокеры и эскалация») — артефакт
всё равно пишется на диск как есть, но статус другой, и работа сама
останавливается, не дожидаясь, что это поймает ревьюер:

```json
{
  "status": "blocked",
  "artifacts": ["<путь>"],
  "assumptions": [],
  "blocking_questions": ["<вопрос>"]
}
```
