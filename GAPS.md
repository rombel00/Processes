# Current limitations

Это краткий реестр актуальных ограничений. Исторические наблюдения сохранены в
[docs/history/GAPS-legacy.md](docs/history/GAPS-legacy.md) и не входят в cold
start.

- Реальные полевые доказательства, контакты с людьми, расходы, публикация,
  production и миграции требуют отдельного допуска владельца.
- Синтетическая критика и desk-исследование не доказывают willingness-to-pay.
- В Windows локальный shell-harness `check-skills.test.mjs` может зависеть;
  канонический контракт проверяется Git Bash/CI на Linux.
- Полноценный внешний пилот коммерческой валидации не выполнялся в исходнике
  процесса: для него нужны отдельный scope, согласие и безопасный контур.
