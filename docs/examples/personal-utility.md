# Пример: личная утилита

Потребность: быстро находить собственные заметки. Маршрут — `personal utility`,
режим — `lightweight`. Агент описывает минимальный локальный прототип и
критерий пользы: пять поисков за неделю должны находить запись быстрее ручного
просмотра. Это не коммерческое доказательство и не повод подключать внешние
сервисы без отдельного решения.
