# Пример: задача бизнеса

Запрос: «сделать экспорт отчёта». Маршрут — `business request`. Сначала
связывают запрос с сегментом, частотой боли и наблюдаемой метрикой. Гипотеза:
экспорт сокращает ручную подготовку отчёта для финансового администратора.

Проверка — пять согласованных наблюдений текущего процесса и порог: минимум
три подтверждения еженедельной боли. Решение не запускает код автоматически:
оно создаёт или отклоняет отдельный пакет разработки.
