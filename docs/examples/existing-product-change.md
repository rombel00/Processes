# Пример: изменение существующего продукта

Изменение: новый экран тарифов. Маршрут — `existing product change`. До
реализации фиксируют текущую конверсию, затронутые сегменты и обратимый
эксперимент (макет или feature flag без публикации). Решение сравнивает
результат с заранее указанным порогом, а не с впечатлением команды.

Публикация, платный трафик, доступ к аналитике и изменение цен требуют
отдельного согласия владельца.
