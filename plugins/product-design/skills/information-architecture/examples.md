# Пример: Information Architecture

## Вход (от пользователя)

> Небольшой сервис записи к мастерам (барбершоп): клиент выбирает мастера и время.

## Фрагмент IA

```markdown
## 2. Sitemap
барбершоп
├── Главная (витрина услуг + CTA «Записаться»)
├── Мастера
│   └── Профиль мастера (услуги, расписание)
├── Запись (выбор услуги → мастер → время → подтверждение)
├── Мои записи
└── Авторизация (вход / регистрация)

## 3. Инвентарь экранов
| № | Экран | Раздел/эпик | Назначение |
|---|---|---|---|
| 1 | Главная | Витрина | Показать услуги и CTA «Записаться» |
| 2 | Список мастеров | Мастера | Выбрать мастера по фото/специализации |
| 3 | Профиль мастера | Мастера | Услуги и расписание конкретного мастера |
| 4 | Выбор услуги | Запись | Первый шаг флоу записи |
| 5 | Выбор времени | Запись | Слоты на выбранного мастера/услугу |
| 6 | Подтверждение записи | Запись | Итог перед отправкой брони |
| 7 | Мои записи | Мои записи | Список активных и прошлых записей |
| 8 | Вход | Авторизация | Вход по телефону/email |
| 9 | Регистрация | Авторизация | Создание аккаунта клиента |

## 4. Глобальная навигация
| Позиция | Элемент | Куда ведёт | Приоритет |
| 1 | Записаться | Запись | Высокий |
| 2 | Мастера | Мастера | Средний |
| 3 | Мои записи | Мои записи | Средний |

## 5. Ключевой User Flow — «Первая запись»
Главная → Записаться → выбор услуги → выбор мастера → выбор времени → подтверждение
   ↓ нет свободного времени
предложить ближайшие слоты
```
